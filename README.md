# greenway-logmobi

## Descrição

GreenWay LogMobi é um projeto de logística urbana sustentável, atuando como **Centro de Distribuição e Last Mile** para e-commerce e parceiros locais. Utiliza mini-unidades de bairro, lockers inteligentes e análise de dados logísticos para organizar o fluxo de pacotes de forma eficiente, rápida e ecológica.

---

## Funcionalidades Principais
- Recebimento e conferência de pacotes via QR code/barcode  
- Armazenagem inteligente em lockers e prateleiras  
- Roteirização otimizada para entregadores e last mile  
- Notificação automática para retirada de encomendas  
- Relatórios de demanda anonimizados por bairro

---

## Público-Alvo
- Consumidores de e-commerce  
- Pequenas e médias empresas  
- Entregadores parceiros

---

## Controle de Estoque

- Método: PEPS (Primeiro a Entrar, Primeiro a Sair)  
- Reposição: semanal/quinzenal ou conforme demanda  
- Estoque mínimo: 3-5 dias para pacotes, 2 semanas para materiais

---

## Dados Logísticos & LGPD
- Coleta apenas de dados essenciais para entrega  
- Anonimização de informações pessoais quando possível  
- Acesso restrito a funcionários autorizados  
- Clientes informados sobre uso de dados e com consentimento
